# Personal Vault

🔐 **Encrypted file vault** — create password-protected rooms to share files, notes, and links across any device.

**Live site:** [https://varsansri.github.io/personal-vault/](https://varsansri.github.io/personal-vault/)

### Features
- Create rooms with a password (AES-256-GCM encrypted)
- Upload files (Excel, images, PDFs, etc.)
- Write and save notes
- Save quick links with labels
- 30 MB storage per room
- Works on any device — just open the link + enter password

### How to use
1. Go to the [website](https://varsansri.github.io/personal-vault/)
2. Create a room with a password, or join an existing room with its ID
3. Share the room link — anyone with the link and password can access
